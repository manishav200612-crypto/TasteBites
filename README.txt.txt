TASTY BITES
Online Restaurant Management and Food Ordering System

PROJECT OVERVIEW
Tasty Bites is a full-stack restaurant management and food ordering
application. It allows users to view food menu items and place orders.

TECHNOLOGIES USED

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Java
- Spring Boot
- Spring Cloud
- REST APIs
- Microservices Architecture

Database:
- MySQL

Build Tool:
- Maven

MICROSERVICES

1. Eureka Server
   Used for service discovery and registration.

2. API Gateway
   Acts as the entry point for client requests to backend services.

3. Menu Service
   Manages restaurant menu information.

4. Order Service
   Manages customer food orders.
